## ⚙️ 실행 방법
 
### 환경 설정
```bash
git clone https://github.com/your-team/your-repo.git
cd your-repo
pip install -r requirements.txt
```
 
### 학습
```bash
python train.py --config configs/default.yaml
```
 
### 평가 / 추론
```bash
python eval.py --weights path/to/weights.pth
```
 
### 디렉터리 구조
```
.
├── assets/        # README용 이미지
├── configs/       # 설정 파일
├── data/          # 데이터셋
├── models/        # 모델 정의
├── train.py
├── eval.py
```
